# Fullstack Bootcamp 🚀

This repository contains my work, projects, notes, and experiments from a full-stack development bootcamp.

The goal of this repository is to document my learning journey as I work through different concepts in frontend and backend development and build projects along the way.

This is a learning-focused repository where I will be sharing the things I learn throughout the bootcamp, including:

* Full-stack applications

* Practice exercises and experiments
* Resources and learning material
